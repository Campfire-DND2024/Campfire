# Campfire web app

The same Campfire app as the Android APK, for iPhones and any web browser. It signs in and syncs with the APK through your Firebase project (campfire-3e79f).

## Put it online with GitHub Pages
1. On github.com, click **New repository**, name it `campfire-app`, set it to **Public**, and create it.
2. Click **uploading an existing file** and drag in every file from this folder (there are no subfolders, so this works from a phone too). Click **Commit changes**.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**, and click **Save**.
4. After a minute or two your link appears there: `https://YOUR-USERNAME.github.io/campfire-app/`

## Installing it on a phone
- iPhone: open the link in Safari, tap **Share**, then **Add to Home Screen**.
- Android: open the link in Chrome and tap **Install app** (or use the APK).

To update it later, upload the new files over the old ones. Players get the update the next time they open the app.
